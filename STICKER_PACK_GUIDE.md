# Sticker Pack Guide — Chronicle Bot

Chronicle поддерживает выбор стикера по настроению момента. Чтобы это работало, стикерпак должен быть собран по определённым правилам.

---

## Как это работает

После записи момента AI определяет его настроение и выбирает стикер из подходящей группы. Группы определяются через **emoji, прикреплённый к каждому стикеру** при создании пака — это стандартная Telegram-функция, её поддерживает любой стикерпак.

---

## Настроения и их emoji

Каждый стикер должен быть помечен одним из этих emoji. Именно по ним бот определяет категорию.

| Настроение | Emoji | Когда используется |
|---|---|---|
| `happy` | 😄 | Радостные, позитивные моменты |
| `proud` | 💪 | Достижения, преодоление, гордость |
| `grateful` | 🙏 | Благодарность, тепло, поддержка |
| `excited` | 🚀 | Азарт, энергия, вдохновение |
| `calm` | 😌 | Спокойствие, умиротворение, отдых |
| `sad` | 😢 | Грустные, тяжёлые моменты |

> Если стикер не подходит ни под одну категорию — пометь его любым другим emoji (например ✨). Он попадёт в резервный пул и будет использоваться при случайном выборе.

---

## Рекомендуемый состав пака

Минимум по **3–5 стикеров на категорию**, чтобы не повторяться.

```
Всего: 24–36 стикеров

😄 happy      — 4–6 шт.
💪 proud       — 4–6 шт.
🙏 grateful    — 3–5 шт.
🚀 excited     — 3–5 шт.
😌 calm        — 3–5 шт.
😢 sad         — 3–5 шт.
✨ резерв      — остаток
```

---

## Как создать пак через @Stickers

1. Открой бота [@Stickers](https://t.me/Stickers) в Telegram
2. Отправь `/newpack` → введи название пака
3. Для каждого стикера:
   - Отправь изображение (PNG с прозрачностью, 512×512px) или анимацию (.TGS)
   - Когда бот спросит emoji — отправь **один emoji из таблицы выше**
4. После добавления всех стикеров — `/publish`
5. Имя пака (например `mypack_by_ChronicleBot`) — это `STICKER_SET_NAME` в `.env`

---

## Как проверить emoji стикеров в готовом паке

Запусти в корне проекта:

```bash
python tools/check_stickers.py
```

Скрипт выведет все стикеры пака с их emoji и покажет, сколько стикеров попало в каждую категорию.

---

## Требования к изображениям

| Параметр | Значение |
|---|---|
| Формат | PNG (статичные) или TGS (анимированные) |
| Размер холста | 512 × 512 px |
| Прозрачность | обязательна |
| Макс. размер файла | 512 KB |
| Стиль | единый — персонаж или набор объектов в одном визуальном стиле |

---

## Пример правильного набора

```
стикер_01.png  →  😄  (кот радуется)
стикер_02.png  →  😄  (кот прыгает)
стикер_03.png  →  💪  (кот с кулаком)
стикер_04.png  →  💪  (кот со звездой)
стикер_05.png  →  🙏  (кот обнимает)
стикер_06.png  →  🚀  (кот летит)
стикер_07.png  →  😌  (кот спит)
стикер_08.png  →  😢  (кот грустит)
стикер_09.png  →  ✨  (кот просто сидит)
```

---

## Что будет, если emoji не совпадает ни с одной категорией

Бот автоматически использует случайный стикер из всего пака — поведение как сейчас. Ничего не сломается.
